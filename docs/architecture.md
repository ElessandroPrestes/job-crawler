# Arquitetura do Framework Universal SDD no Projeto

A arquitetura orienta o processo de desenvolvimento, não apenas o código.

- **Specs**: Definem "o que" será feito e "por que". (Armazenadas em `specs/`)
- **Tasks**: Detalham "como" será feito passo-a-passo. (Armazenadas em `tasks/`)
- **ADRs**: Registro de Decisões de Arquitetura. (Armazenadas em `adr/`)
- **Reviews**: Evidências de QA e code reviews. (Armazenadas em `reviews/`)
