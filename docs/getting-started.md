# Primeiros Passos

Para novos desenvolvedores ou agentes de IA entrando no projeto:

1. Leia `README.md` e `PROJECT.md`.
2. Familiarize-se com a base de código e a stack (PHP 8.2).
3. Verifique os padrões em `standards/`.
4. Siga os fluxos descritos em `workflows/` (ex: `workflows/feature.md`) para criar novas funcionalidades.
