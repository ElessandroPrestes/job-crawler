# Papéis e Responsabilidades dos Agentes

Definição de quem faz o quê no ciclo de vida do desenvolvimento.

- **Humano (Product Owner / Tech Lead)**: Aprova SPECs, valida UX/UI, dá a palavra final em ADRs.
- **IA (Desenvolvedor)**: Escreve código baseado na TASK, escreve testes, documenta mudanças.
- **IA (Revisor)**: Verifica se o código atende à SPEC, checa padrões (standards) e sugere melhorias.
